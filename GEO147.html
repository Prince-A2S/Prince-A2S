03 · Machine-learning model

Feed-forward neural network (trained live, in your browser)

A compact multilayer perceptron predicts UCS from soil matrix type, water content, VBP%, and block size. It is implemented from scratch in JavaScript (manual forward pass, backpropagation, and Adam optimizer — no external ML library), so it trains entirely client-side when you click the button below.

05 · Model comparison

Twelve supervised models, trained on the same split

Clicking Train model in section 03 now trains eleven classic regressors from scratch in JavaScript, alongside the ANN, on the exact same one-hot / standardized feature matrix, log1p-standardized target, and 80/20 train/test split — so every metric below is directly comparable. All figures are computed after inverse-transforming back to original UCS units (kN/m²).

1–2. Linear & Ridge Regression

ŷ = β₀ + Σ βᵢxᵢ  ·  β = (XᵀX + λI)⁻¹Xᵀy
Closed-form ordinary least squares (λ=0) and L2-regularized ridge (λ=2) via Gauss–Jordan matrix inversion. Intercept is never penalized.

3. K-Nearest Neighbors

ŷ(x) = (1/k) Σi∈Nk(x) yᵢ
Averages the target of the k=5 nearest training points in standardized feature space (Euclidean distance). No training phase — purely a lookup.

4. Decision Tree

split* = argminf,t [ nₗVar(yₗ) + nᵣVar(yᵣ) ] / n
Recursive binary splits (CART) choosing the feature/threshold pair that most reduces weighted target variance, to max depth 6.

5. Random Forest

ŷ = (1/T) Σt=1..T Treet(x)
Bagged ensemble of 30 decision trees, each on a bootstrap resample with a random ~70% feature subset, averaged to reduce variance.

6. Gradient Boosting

Fm(x) = Fm−1(x) + ν·hm(x)
40 shallow trees (depth 3) fit sequentially to the residuals of the previous stage, learning rate ν = 0.1.

7. Lasso Regression

min ‖y−Xβ‖² + λ‖β‖₁
L1-penalized linear regression via coordinate descent with soft thresholding (λ=0.02) — drives weak-feature coefficients exactly to zero.

8. Elastic Net

min ‖y−Xβ‖² + λ₁‖β‖₁ + λ₂‖β‖²
Combines Lasso's sparsity (λ₁=0.02) with Ridge's stability (λ₂=1) — a middle ground between the two.

9. Polynomial Regression

ŷ = β₀ + Σβᵢxᵢ + β_a·VBP² + β_b·d² + β_c·VBP·d
Degree-2 expansion of the VBP% and block-size terms (plus their interaction), then fit with ridge-regularized OLS.

10. Support Vector Regression

min ½‖w‖² + C·Σ max(0, |ŷᵢ−yᵢ|−ε)
Linear-kernel SVR with an ε-insensitive loss (ε=0.05, C=2), fit by subgradient descent — errors inside the ε-tube aren't penalized.

11. Extra Trees

ŷ = (1/T) Σ Treet(x), split thresholds drawn at random
Like Random Forest, but each split threshold is drawn uniformly at random rather than optimized — more randomness, often less overfitting.

07 · Explainability (SHAP)

SHAP analysis — supervised and unsupervised models

SHAP (SHapley Additive exPlanations) splits every prediction into one contribution per input feature, so that base value + Σ SHAP = model output exactly. Because there are only 4 inputs (supervised) or 3 inputs (unsupervised), the Shapley values below are computed exactly by enumerating every feature coalition (16 and 8 coalitions respectively) — no sampling approximation. Absent features are filled in from a background set (marginal / interventional SHAP). Matrix type and water content are each treated as one feature, so their one-hot columns are not split apart.

08 · Reference equations

Factor of Safety — Indian & American standard methods

Five relations connect the predicted UCS to a slope-stability Factor of Safety. The first four are established methods from Indian and American geotechnical practice; the fifth is a new relation proposed here, derived from this dataset's ANN model, for scaling FOS by the block-reinforcement level.

1. UCS → undrained cohesion

IS 2720 (Part 10):1991 — Determination of Unconfined Compressive Strength · ASTM D2166/D2166M-16
cu  =  qu / 2
Valid for saturated, fully cohesive soil under the φu = 0 (undrained) assumption of the unconfined compression test. c_u = undrained shear strength / cohesion (kN/m²) · q_u = unconfined compressive strength, i.e. the model's predicted UCS (kN/m²).

2. Infinite Slope Method

Classical limit-equilibrium method (Taylor 1948; Terzaghi & Peck) — used in both IS and USACE practice for long, uniform slopes
FOS  =  cu / (γ · H · sin β · cos β)
γ = soil unit weight (kN/m³) · H = vertical slope height (m) · β = slope angle from horizontal (°). Assumes a shallow planar failure surface parallel to the slope face and no seepage/pore pressure.

3. Taylor's Stability Number Method

Taylor (1948) stability charts — φ = 0 case; standard reference in Indian & US textbooks (e.g. IS 7894:1975 background, USACE EM 1110-2-1902)
FOS  =  cu / (γ · H · Ns)
N_s = dimensionless stability number, read from Taylor's chart as a function of slope angle β (this tool interpolates a standard φ = 0, firm-base table). Lower Ns → flatter, more stable slopes.

4a. Ordinary Method of Slices (Fellenius, 1936)

IS 7894:1975 — Code of Practice for Stability Analysis of Earth Dams · USACE EM 1110-2-1902 — Slope Stability
FOS  =  Σ [ c′·l + (W·cos α − u·l)·tan φ′ ]  /  Σ (W · sin α)
Slope divided into vertical slices along a trial circular slip surface. W = slice weight · α = base inclination of the slice · l = slice base length · c′, φ′ = effective cohesion & friction angle (u = 0 / total stress form used here, with c = cu, φ = 0 consistent with the UCS test condition).

4b. Bishop's Simplified Method (1955)

IS 7894:1975 · USACE EM 1110-2-1902 — the standard, more accurate refinement of the ordinary method
FOS  =  Σ [ (c′·b + (W − u·b)·tan φ′) / mα ]  /  Σ (W · sin α)   ·   mα = cos α (1 + tan α·tan φ′ / FOS)
b = slice width. Solved iteratively since FOS appears on both sides (via mα); this tool iterates to convergence (≤ 50 steps, tolerance 10⁻⁶). Reduces exactly to the Fellenius/infinite-slope result when φ′ = 0, which this tool verifies internally.

5. Proposed Reinforcement Improvement Factor (new)

Derived here from the ANN regression on this dataset — not a published standard; use as a design-comparison aid, not a certified value
IF(VBP, d)  =  ÛCS(VBP, d) / ÛCS(0, 0)      FOSreinforced  =  FOSunreinforced · IF(VBP, d)
Because every method above is linear in cu, and cu is linear in UCS (eq. 1), any change in predicted UCS from adding block reinforcement (VBP%, block size d) scales the resulting FOS by the same ratio. IF is the ANN's predicted UCS at the chosen VBP/block size, divided by its prediction at VBP = 0 (unreinforced) for the same matrix type & water content. The FOS calculator below plots this relation directly.
This tool is an educational / preliminary-design aid built from a single lab dataset and a small ANN. It is not a substitute for a certified geotechnical engineer's site-specific stability analysis. Design guidance (e.g. IS 7894, IS 14458, USACE EM 1110-2-1902) generally recommends a minimum FOS of about 1.5 for long-term (steady-state) slope stability and 1.2–1.3 for temporary or rapid-drawdown conditions — always confirm the applicable value for your project and jurisdiction.
